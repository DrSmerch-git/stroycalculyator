# СтройКалькулятор

Исходники сайта [stroycalculyator.ru](https://stroycalculyator.ru) - калькуляторы материалов для ремонта.

## Что это

Статический сайт без сервера, сборки и внешних библиотек: чистый HTML, один файл CSS, один файл JS. Все расчёты выполняются в браузере пользователя, данные никуда не отправляются.

|Калькулятор|Считает|
|-|-|
|[Плитка](kalkulyator-plitki/)|плитки и упаковки для пола и стен, с проёмами и запасом|
|[Ламинат](kalkulyator-laminata/)|ламели, упаковки, подложка|
|[Обои](kalkulyator-oboev/)|рулоны по полосам, с раппортом и проёмами|
|[Краска](kalkulyator-kraski/)|литры и банки по слоям|
|[Стяжка](kalkulyator-styazhki/)|объём раствора и мешки пескобетона|
|[Гипсокартон](kalkulyator-gipsokartona/)|листы ГКЛ и саморезы|

Каждый расчёт сопровождается блоком «Как мы это посчитали» с формулой и подставленными числами - результат можно проверить вручную.

## Структура

```
index.html                  главная
kalkulyator-\\\*/index.html    страницы калькуляторов
assets/style.css            стили
assets/calc.js              движок расчётов
CNAME                       домен для GitHub Pages
robots.txt, sitemap.xml     служебные файлы для поисковых систем
```

Движка нет: страница описывает поля и функцию расчёта, всё остальное делает `calc.js`.

## Локальный запуск

Открыть `index.html` в браузере — сайт работает и по `file://`, сервер не нужен.
