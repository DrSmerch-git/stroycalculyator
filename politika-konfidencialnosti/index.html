Политика конфиденциальности

Сайт не собирает и не хранит ваши данные. Для статистики посещений подключён счётчик Яндекс.Метрики.

Цели

Сведения о посещениях нужны чтобы:

  • понимать, какие калькуляторы востребованы и по каким запросам приходят посетители;
  • видеть, где на страницах возникают трудности, и исправлять их;
  • следить за работоспособностью сайта.

Правовые основания

  • согласие посетителя выражается в продолжении работы с сайтом. Отказаться можно, отключив файлы cookie в настройках браузера;
  • исполнение обязанностей, возложенных законом, в рамках 152-ФЗ «О персональных данных».

Статистику собирает и обрабатывает сервис Яндекс.Метрика (ООО «Яндекс») в соответствии со своими документами.

Какие данные собирает Яндекс.Метрика

Для понимания посещаемости используется сервис Яндекс.Метрика. Он собирает технические сведения о посещении:

  • IP-адрес и приблизительная географическая локация по нему;
  • тип браузера, операционной системы и устройства;
  • какие страницы вы открыли, сколько времени провели и куда нажали;
  • адрес страницы, с которой вы перешли на сайт.

Эти данные нужны только для статистики. Мы не используем их для идентификации конкретного человека.

Файлы cookie

Cookie - небольшие текстовые файлы, которые хранит браузер. На этом сайте они ставятся счетчиком посещаемости, а не самим сайтом. Вы можете отключить или удалить их в настройках браузера.

Передача данных третьим лицам

Мы не продаём данные и не передаём их никому, кроме сервисов, которые обеспечивают работу сайта:

  • ООО «Яндекс» - обработка статистики через Яндекс.Метрику. Условия описаны в политике конфиденциальности Яндекса.
  • GitHub Inc. - хостинг статических файлов сайта (GitHub Pages). Сервер хостинга технически видит IP-адрес и заголовки запроса при загрузке страницы, как любой веб-сервер.

Меры по защите данных

Мы принимаем меры, соразмерные характеру обработки: на сайте нет сохранённых личных данных.

  • сайт статический: на сервере нет базы данных, нет учётных записей и нет сохранённых личных данных посетителей;
  • значения, введённые в калькуляторы, не передаются и не сохраняются;
  • отчёты статистики доступны только владельцу сайта.

Ваши права

Вы можете в любой момент отказаться от сбора статистики, отключив cookie в браузере.

Изменения политики

Эта страница может обновляться: например, при подключении новых сервисов. Актуальная версия всегда доступна по этому адресу.
